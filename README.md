# ロジカルバナナ

AI と連想ゲーム（マジカルバナナ）で遊ぶプログラムです。お題の言葉から連想した言葉を入力すると、AI が言葉の近さを点数にし、次の言葉を連想して返します。

言葉の意味は、青空文庫の文章で学習した言語モデル（LSTM）の単語ベクトルで表しています。

## 遊び方

画面の例です（数字と AI の答えは実行ごとに変わります）。

```text
--- ロジカルバナナ！ ---
プレイヤー(1/10)：【バナナ】といえば？ > 果物
　　　　　　　　　　いいね！ (類似度: 0.312)
　Ａ　Ｉ　(1/10)：【果物】といえば？ > 〇〇
```

1. 最初のお題は「バナナ」です。連想した言葉を入力して Enter を押します。
2. お題と入力した言葉の類似度が 0.25 以上なら「いいね！」、未満なら「似てないよ～」と表示します。
3. AI が入力した言葉から次の言葉を連想し、それが次のお題になります。
4. 4回で終わり、最後に全部の回の結果を表にして表示します。

学習した語彙にない言葉を入力すると、類似度は 0 になり、AI は語彙からランダムに言葉を選びます。

## 仕組み

単語ベクトルは、言語モデルの最初の層（Embedding 層）の重みを使います。

- **類似度**：お題と入力した言葉のベクトルのコサイン類似度です。
- **AI の連想**：次の2段階で決めます。
  1. 入力した言葉に近い言葉を、近い順の2〜6番目からランダムに1つ選びます。
  2. 「入力した言葉 − 1で選んだ言葉 + 太陽」のベクトルに最も近い言葉を答えにします。
     すでに出た言葉と、計算に使った3つの言葉は除きます。見つからなければ1で選んだ言葉を答えにします。

「太陽」を足すことで、ただの類義語ではなく少しずれた言葉が返るようにしています。

| ファイル | 役割 |
|---|---|
| `logical_banana.py` | ゲームの本体（類似度の計算、AI の連想、結果の表示） |
| `better_rnnlm.py` | 2層の LSTM の言語モデル（Dropout、weight tying あり） |
| `aozora_vocab.pkl` | 語彙（単語と ID の対応表） |

## 今後の課題

- 画面には「(1/10)」と出ますが、実際は4回で終わります（`for i in range(4)`）。
- 入力した言葉が語彙にあるかを確かめないので、語彙にない言葉でもそのまま次に進みます。
